One tagline for make.fun, at most 100 characters: build an agent,
enter the bounty, win the reward — make.fun pays the best.

## Run

```sh
node main.ts
```

Writes the tagline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–100 characters.
